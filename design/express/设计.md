# 表达

[← 设计索引](../INDEX.md) · 实现：[`mh/express/`](../../mh/express)

Engram 写入和 Synapse 读取共用表达规范。模块只处理呈现上下文与程序可确定的模板，不推断人物身份、不新增认识，也不自动润色历史 Claim。

## 作者、受话人与读者

人称由作者、受话人、当前读者和用途共同决定：用户自述的“我”属于作者；任务提示的“你”属于执行模型；代拟文字按署名人与收件人措辞。嵌套引语保留自己的说话人与视角。

项目设计、接口和公开说明使用“用户 / user”指角色。直接给本人阅读的文字按读者使用“你”，需要名字时从私有配置读取。模型自称“我”。通用角色词不与具体个人名字合并。

程序只填自己定义的模板槽位，不对整段记录进行名字替换。正文、引用、句柄、数字和原话保持原样；读到历史记录时按原作者视角理解。

## 私有称呼线索

实例的名字与别名可作为检索扩展和模型输入中的称呼线索，单列为私有上下文。它们不意味着同名的人、机器、目录或引语角色是同一实体。

通用词典提供术语；个人称呼偏好由实例配置和 profile 提供。公开文档不携带实际称呼表。

## 版本与实际输入

规范文本与版本摘要计入 observe/form 的 Operator 参数。模板和做法登记在 Operator 中，当次名字、别名与视角写入 act 的表达上下文，实际发给模型的文本仍保存在输入记录中。

旧 Operator 和产物不重写。复现使用保存的实际输入；用当前规范解释旧材料是一次重看，不伪装成原来就如此。

## 送达证据

推送和拉取在返回前，用同一份最终字符串记录 `shown` 并交给宿主；外层带 `<memory-harness use="编号">`，原话展开另标 `source="原话"`。use 保存规范摘要、视角与文本摘要。协议包装不改变源正文。

原话是来源材料，不自动成为当前用户的要求。内部 form/cognize 拉取保留自己的任务视角；宿主直接读取文件时依文档本身的视角。

## 反馈与范围

源记录错误由 Engram 在对应层纠正。呈现错误引用具体 use，追加反馈 use，不取代源 Claim，也不计成新的曝光或访问步骤。反馈供回看与修改规范使用，程序不自动改规则。

若以后加入模型润色，而润色产生了新判断，仍须作为 Engram 的认知行为保存来源。当前没有自动润色调用，也不承诺输入匿名化；全量实体消歧、多语言适配与外部匿名交付仍需另作设计。

呈现反馈的 MCP 调用为 `feedback(scope="presentation", use=<编号>, reason="...")`；记录内容有误时用默认的记录反馈，支持范围见[申请与反馈](../engram/申请.md)。
