# 词典

[← 设计索引](../INDEX.md)

这里解释当前设计中的术语。词头按原项目格式维护：`/` 连接同一东西的不同叫法，全名在前；不同事物分别成条。源码运行时可读取这些词头补充术语别名；个人名字、别名和工作区映射仍从私有实例配置读取。

## 总体与模块

**Memory Harness / mh**

套在助手外面的记忆基础设施；`mh` 是代码包与命令名。

**总体设计 / global**

全局目标、不变量、分工、词典与通用安装配置。

**Engram / engram**

写的一侧，保存原话、观察、形成与认知的历史。

**observe / 观察**

从原话写出 event。

**form / 形成**

从 event 整理会话记录、话题与线。

**cognize / 认知形成**

从会话结构提出跨分支的 cognition；自动形成尚未接入。

**Synapse / synapse**

读的一侧，负责推送、拉取、导航与 use 足迹。

**rhythm / 节律**

调度过程的运行时机、并发与额度。

**表达 / express**

写入与读取共用的人称、来源视角与呈现规则。

**公开发布 / release**

公开材料选择、打包资源、清单与同步边界。

## 数据与交互

**宿主**

承载助手的环境，目前内置 Claude Code、Codex、dsh 适配。

**用户 / user**

与助手交互的角色；面向本人写的文字按读者使用“你”，模型自称“我”。

**工作区**

会话所属的项目，由实例映射、会话更正和目录信息确定。

**Occurrence**

实际发生过的一次表达、认知行为或读取；时间属于它。

**Claim**

被表达的内容；存在不等于真实、被认可或已验证。

**Operator**

一套做法：模型、提示词、隔离方式、窗口与影响输入的参数。

**act**

一次认知行为，保存实际输入、原始输出、原因、成本和错误。

**event / E**

observe 从一轮或多轮原话中写出的观察。

**judgment / J**

form 的判断；当前常驻流程主要做挂线等结构判断。旧版逐句 J 保留历史，新的跨会话推演尚未接入。

**cognition / C**

自我的特质：抽象 C（暂名“理”）是一条条准则（世界观细则、方法论、行为准则、冲突的解法，手记扉页里的就是），具体 C（暂名“事”）是准则的实际案例，一件完整发生过的事，既是警醒也是佐证。两者是看同一问题的两种视角，抽象 C 之于具体 C 如话题线之于陈述。平时不加载，由联想按输入注入；扉页是常驻的那几条。事的地图由线和骨架给，不由 C 给；当前已有程序接口。

**会话记录**

按会话先后整理的陈述，引用来源 E。

**陈述 / S**

会话记录中的一条内容，S 序号在话题内定位。

**会话入口 / 话题 / T**

会话记录的入口，包含名字、主题、停在与索引词。

**停在**

会话结束时定下、完成或仍悬而未决的内容。

**话题线 / 线 / L**

为检索组织若干会话入口的结构；相关目标要能解释为什么往这里找。

**挂线 / attach**

把入口放到线上的结构判断，作为可反馈修正的初值。

**骨架**

人工核对过的目录或文件层级；为 form 提供结构参照。

**Atlas**

认知及形成认知的方法；设计中节点是 C，当前导航主要沿骨架、线、话题展开。

**View**

选用哪些来源版本的读视图；更新视图不抹去其他版本。

**use**

一次推送、拉取、导航或相应反馈的发生记录；保留目的、版本和实际返回文本。

**曝光**

足迹记下给到了什么内容；不等于读懂或用上。

**在场**

写回复时某条记忆仍在上下文中；当前部分分析仍按曝光近似。

**有回应**

后续拉取、显式引用或复述等可观察行为。

**申请 / request**

请求某一层重做或修订；与已经写出正确内容的反馈分开。给 form 的申请带级别（陈述、入口、挂线、单位），一级的问题不越到下一级，只重做那一级的步骤。

**手记**

会话接入时送入的一份上下文：扉页（内核 `core.md`，也叫内核，几乎不改）、工具说明、近况（项目现状）和当前环境。读了会当作自己相信的经历、记不太住时重读的那份；不用“开场”这类会话开关的说法。

**视野 / 作用域**

视野是一层产出时看到的范围（输入），作用域是它写下的东西能覆盖的范围（输出）。借上一层的视野：每一层要产出得好，需要上一层那么大的视野，作用域仍是本层；越不过的部分由上一层自己做。预览之于事件，骨架之于 form；form 的作用域是会话，超出会话的合并归 cognize。

**收回 / 放回（prune / unprune）**

observe 的程序动作：把判为没有必要交给 form 的事件收回，之后可以放回，按先后、后一次说了算，事件本身不删。出处里有用户原话的不收。

**首屏的展示预算**

一次查询首先给出的有限位置。不依赖模型主动翻页或选择条数，而是以固定的 6–8 条比较展示效率。

## 命名与句柄

命名上，过程用动词 `observe`、`form`、`cognize`；产物用名词 `event`、`judgment`、`cognition`；Operator 角色用施事名词 `observer`、`former`、`cognizer`。程序标识符使用英文，记录内容使用 UTF-8。

当前常见句柄是 `L3`、`T5`、`L3:T5:S1`、`E123`、旧版 `J123` 和骨架 `k-…`。C 的程序接口已经存在，面向对话的导航尚未接入。只写稳定节点编号、动态展示路径的分层句柄方案仍属[后续设计](../engram/form/设计.md#分层索引设计方向)。
