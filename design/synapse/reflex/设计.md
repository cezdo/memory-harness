# 反射

[← Synapse](../设计.md) · 实现见 [`mh/synapse/reflex/`](../../../mh/synapse/reflex)。

反射是在手记近况开头直接给出的一句话现行答案，适用于反复用到、失效时能察觉的程序性事实。条目可以带记忆句柄，便于需要时回查来路。失效时修改来源文件内的条目并更新句柄。

- **环境级**适用于所有接入的工作区。实例用 `[resources].reflex` 指定 Markdown 文件。
- **工作区级**写在该工作区近况源文件的 `## 反射` 一节，随该工作区送达。

两级条目合并去重，环境级在前。可校验记忆库时跳过引用已失效的条目。公开包提供这套机制，具体条目由实例维护。
