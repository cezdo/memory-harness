# Synapse

[← 设计索引](../INDEX.md) · 实现：[`mh/synapse/`](../../mh/synapse)

Synapse 让已有认识参与现在，也让助手知道还有什么可查。它只读 Claim，只追加 use：它不改变“有什么”，只改变“哪些 Claim 此刻在场”。它产出的都是 Occurrence：use（送了什么、读了什么）、写给 Engram 的申请，以及状态变化（联想开关、yorimichi、提权）。

## 结构

按功能分，每个功能内部都是一次 S→R→P：接收宿主事件，决定哪些 Claim 现在该参与、给多少，再排版送出并记下送了什么。

| 功能 | 管什么 | 什么时候 |
|---|---|---|
| 手记 | 扉页（内核）、工具说明、近况、环境 | 会话开始 |
| 每一轮 | “没印象”提示；联想 | 用户每说一句 |
| 拉取 | evoke、relive、roam、检索 | 助手主动；form 起名、挂线也用 |
| 内核态 | 内核的提权、拦截与日志 | 用户 `/mhcore` |
| 足迹 | use、访问树、引用回填 | 事后 |
| 宿主接入 | Claude Code、Codex、dsh 的适配；MCP 服务 | 一直 |

## 手记

会话接入时送一次（新会话、恢复、清空、压缩之后），按稳定到易变的顺序：扉页（内核 `core.md`）、工具与句柄说明、近况、当前环境，包在 `<memory-harness>…</memory-harness>` 中；原话带 `source="原话"`，送达编号只记在库里、不进标签。叫手记，是因为助手读了会当作自己相信的经历、记不太住时重读的那份；目标是无感地切换会话。每次送出记一条 use。

工具一节只给名字、主参数名、一句用途和句柄格式：宿主延迟加载时助手看不到工具说明，会凭印象写错参数；其余细节只写在 MCP 工具说明里。

扉页是每次接入都需要的稳定内容，几乎不改；内核和近况从实例配置指定的私有资源读取，缺失时省略，公开仓库不提供个人内核。仓库的做事规则由宿主自己的文档机制加载。

近况由整理循环事先编好，只推异常：目录活动、最近提交、未提交的改动及是哪段会话碰的、服务异常、和上一次相比变了的检查项、最近停下的几段会话（已形成的给句柄，用户点名再拉取）。登记了待办清单的工作区，还推清单里落后、和设计对不上的地方，以及模型每天写的一份更新稿的提示；稿由在场的会话看过再改，不直接改仓库。近况是缓存快照，不是实时健康检查。`mh boot` 预览当前工作区的手记。

## 每一轮

**“没印象”提示**：用户输入里足够特别、记忆中逐字找不到的名词，提示一句，免得助手把“记忆里没有”和“外面不存在”混为一谈。程序按词性、通用词库、词典词头和实例的静默词表过滤；一个词说过一次就不再说。

**联想**：程序在陈述里找和这句话相关的内容，不调模型，按话题归并送出（第一行 `[Souhatsu]`，每个话题带句柄和一条命中片段）。字面命中之后，候选由字面和向量两路交替给出（各取一条、去重）；送不送仍由字面的档定——向量的分数分不开平常话和真要的。送多少由 **yorimichi** 定：助手在对话阶段变了时用 MCP 工具 `yorimichi` 记下允许拐几次，没变不调；没记过是 1。0 只给收窄到一被打断就容易出错的一件事（排查一个故障、逐行改一段代码），在干活本身不算；聊开了、话题在散是 2–3。用户的 `/no-souhatsu`、`/do-souhatsu`（Codex 写 `$`）关掉或恢复这个会话的联想，优先于 yorimichi，“没印象”照旧。不送的候选照样记录，但不算曝光。dsh 还没接联想开关。

## 拉取

查法跟着问题走：不必学一套固定的查法，直接用自然语言问就该拿到要的；同一份结构，给哪一部分按这句话想知道什么定（关系、含义、还是碰到一个词想起相关的），没有偏好就给最接近的那一个，不把结构整个摊开。

| 工具 | 参数 | 行为 |
|---|---|---|
| `evoke` | 几个查询词 | 按相关度找线、话题、骨架和陈述，命中给正文；少而准时先列陈述 |
| `relive` | 一个或多个句柄，可带 `near` | 按位置和结构读，可展开来源、原话与历史 |
| `roam` | 工作区或节点，可空 | 一层层走，适合不知道查询词时 |

看任何内容都守 6–8 条的窗口：`evoke` 一页 6–8 条，同一轮再查同样的词就是接着往下；页脚写这一轮前面给过多少条不再列、往下还有的按同时含几个词分层报数，只沾到一个词的不报个数；末尾提醒用到了就在正文里标〖〗，引用回填只认它。`relive`、`roam` 一页 8 条，只能翻页。`relive` 给一条陈述时默认只给它自己，带 `near` 才给所在话题前后各 3 条；话题超出一页、form 写下过和现在主列一致的会话结构时先给结构（问题下排回应它的方向、判断、遗留，证据缩进一层），没有就先给按预览分组的目录；来源按分句排，每条来源挂到意思最像的那一句，不到两句或对不上的照写入顺序。层级先用写入时已有的结构（预览分组、轮、子线），不在写入时为所有内容预先造层级。`relive` 不重新按相关度挑选，旧版 J 能按句柄回溯但不进 evoke。完整的分层句柄方案尚未落地，见 [form](../engram/form/设计.md#分层索引设计方向)。

form 起名、挂线和 evoke 共用 [`retrieve.py`](../../mh/synapse/pull/retrieve.py)，纯程序。字面有索引词匹配和 BM25（ASCII 词加汉字二元组）两路，各取候选再合并；工作区里过于常见的词不单独触发。查词按空白切开、每段算一个词：陈述认正文，话题、线、骨架认名字、主题、索引词和停在。多词时不设硬的“且”——真实查词多是同一件事的几种说法，全部“且”起来几乎全空；按“同一处同时含几个词”分层：同一处是话题自己或它的一条陈述，不把几条陈述并起来算；含得多的在前，同层先比词的稀有度、再比 BM25。

只有同时含两个以上词的陈述少而准时（只有一个词时含这个词）才先列陈述，否则只给话题；话题行写含哪几个词，结果行被〖〗引用过的标出次数（只标，不进排序——拿热度排序试过，真被读下去的话题反而往后）。页头先说同时含全部词的有几个；一个没有，就说去掉哪个词还剩几个，给个松开的方向。陈述行带日期，现状题里新旧两条才分得出先后。最小给到哪一层这类参数不对外露：助手用不到，还会被拿来绕开窗口。

字面之上再加一路向量：查询拼成一句，找最像的陈述和话题，和字面的顺序按名次合并（RRF），只有向量认得出的话题标“意思相近”；分层、页头、列陈述照旧按字面。向量从陈述算出来、可随时重算，不是 Claim。服务可配、可缺席，没配或连不上就只用字面，足迹记下这次没有向量。

## 内核态

内核默认只读。用户以 `/mhcore <要求>`（Codex 写 `$mhcore`）开一轮编辑窗口，这一轮结束、下一次输入或超时后关闭。编辑类工具在窗口外改内核会被拒绝；每次工具调用后比对快照，改动追加进 `$MH_HOME/kernel-log.jsonl`，窗口外发现的标为未登记（发现者不等于修改者）。日志可照 dmesg 一条一行地读：`python3 -m mh.synapse.push.elevate log`。

这是工具路径上的约束和审计，不是文件系统权限隔离：shell 命令不完整解析，钩子出错时放行并记录。dsh 尚未接入。安装先预览再执行：

```sh
python3 -m mh.synapse.push.elevate
python3 -m mh.synapse.push.elevate --apply
```

## 足迹

每次推送、拉取和导航保存 use：会话、目的、版本、查询、返回了哪些记录和实际送达的文本；交互、预取、回放、开发和内部拉取分别标记。曝光是给到了什么，在场是回复时仍在上下文，有回应是后续的拉取、引用或复述；“用上了”“读懂了”不由模型自评。

访问树从 use 推出读取路径。引用回填把助手正文里〖〗标出的记忆连回陈述：写了句柄的由程序直接连，没写的先字面检索候选，再让模型在一个问题里选一条或“都不是”。

## 宿主接入

三个宿主共用同一套入口，各自适配消息封装、会话标识和生命周期：Claude Code 用钩子（手记 `python3 -m mh inject`，每一轮 `python3 -m mh.synapse.push.associate`）；Codex 用安装器写入钩子和 MCP 配置（`python3 -m mh.synapse.hosts.codex.install --help`），新钩子需在 `/hooks` 里信任；dsh 用 [`hosts/dsh/`](../../mh/synapse/hosts/dsh/) 的插件。会话标识会在清空、恢复后改变，接入钩子把当前会话登记在数据目录，MCP 按父进程读取。dsh 上恢复的会话不重推手记，只在还没开始过一轮、待发里也没有它的手记时补送一次（宿主重启会撤掉没说过话的会话里待发的手记）。

钩子每次现起进程，吃工作区里的最新代码；拉取的服务进程吃它起来那一刻的代码，每个宿主一个：Claude Code、Codex 一段会话一个，dsh 一个 dsh web 一个、所有会话共用。改了拉取要等宿主重启才进得去，改钩子下一轮就生效。

MCP 服务是 stdio JSON-RPC（`python3 -m mh.synapse.pull.mcp`），主会话可用的工具只有 `evoke`、`relive`、`roam` 和 `yorimichi`；`feedback` 已撤下，源记录的修正走命令行或 form 的反馈，呈现错误另记一条反馈 use，见[修正机制](../engram/申请.md)。按 schema 校验参数，写错时返回具体错误与参数表。安装、启动、重启都由明确操作完成；改了入口要重启宿主、用真实事件验证。

### 可选依赖

“没印象”提示与联想使用 LTP 和可选通用词库，由 `MH_LTP_PYTHON`、`MH_LTP_MODEL`、`MH_LEXICON` 指定，需自行准备，默认路径见[使用说明](../global/使用.md)。引用回填 `mh backfill` 需要 TypeSafe SDK（`MH_TYPESAFE_PYTHON`），凭据在 `~/.config/memory-harness/typesafe.env`（`TYPESAFE_API_KEY`，可选 `TYPESAFE_MODEL`）。向量一路要一个可用的向量服务，在实例配置里给地址；没有就只用字面。
